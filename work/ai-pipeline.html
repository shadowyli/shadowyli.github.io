选手定妆照管线

实际业务流程示意
  1. INPUT选手照片 + 赛事要求

    输入原始照片，明确服装、背景与交付规格。

  2. GENERATEAI 生成与形象调整

    按赛事风格调整服装与背景，关注人物身份保持。

  3. PROCESS抠图、识别与对齐

    结合 UNIFACE 人脸识别，对齐并按指定尺寸裁切。

  4. OUTPUT规范导出与验收

    转换格式，输出统一规格，由专业人员确认效果。

生成用 AI，准确性用成熟工具。

Logo、品牌资产与固定版式保留原件；Canvas 做精准适配，FFmpeg 处理动效。选型同时考虑效果、速度和成本。

多规格营销物料

已有素材与版式 → 多图层适配 → 裁切、压缩、转换格式 → 按资源位命名归档。

战队 Logo 延展

上传 Logo → 自动加描边 → 延展多种尺寸 → 分类与命名，避免重复人工操作。

让同事掌握这些方法

编写 ComfyUI / n8n 手册，用内部培训、实操作业和项目带教传递搭建方法。

  • 工具调用

REQUEST业务表达需求

填写业务参数，或用自然语言描述目标。

拆解需求，选择管线与工具。

EXECUTE服务执行与检查

调用接口、跟进任务，核对规格与效果。

DELIVER交付或转人工

汇总结果；失败重试，无法确认则升级处理。
